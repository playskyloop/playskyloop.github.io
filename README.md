# playskyloop.github.io (not published)

Static files for GitHub Pages. To publish, make a repo called `playskyloop.github.io` under the
playskyloop account, add these files to the root, and turn on Pages for the main branch.

- index.html: home
- privacy.html: privacy policy (game link: https://playskyloop.github.io/privacy.html)
- delete-data.html: deletion page (game link: https://playskyloop.github.io/delete-data.html)
- assets/: CSS, icon, title font (Russo One, SIL OFL; licence included)

The links in the game live in `src/shared/appLinks.ts`.
